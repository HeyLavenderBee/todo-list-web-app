## Todo List Web App
A to-do list web application made using Angular.
<br>
Organize your to-dos with this web app!
<br><br>
Create to-dos, edit and drag and drop them the way you like.

### Libraries used
- Cdk Drag Drop
- Ng Icons (mono-icons)
- Angular Material Dialog
